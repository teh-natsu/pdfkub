# PdfKub app icon

<img src="pdfkub.svg" alt="PdfKub app icon: a paper page with an orange speech bubble saying ครับ, on indigo" width="128">

**Idea:** a document that answers you politely. "ครับ" (*khrap*, the "Kub" in PdfKub) is the polite
word Thai speakers end a sentence with; here it sits in a speech bubble over a page.

**Palette:**

| Colour | Hex | Used for |
|---|---|---|
| Indigo (app colour) | `#5a4ff0` → `#2d2391` | the full-bleed field, top-left to bottom-right |
| Paper | `#fffaf2` | the page |
| Lavender | `#e3dcf7`, `#cfc9f5` | the folded corner and the text lines |
| Saffron | `#ffb02e` → `#ff7417` | the speech bubble, top to bottom |
| White | `#ffffff` | ครับ |

**Tile:** `viewBox="0 0 512 512"`, a rounded square with `rx=112` that clips everything. Windows and Linux
icons use the full-bleed tile. macOS icons put it on Apple's grid (an 824 px body centred on a transparent
1024 px canvas).

**Small sizes:** at 24 px and below the word can't be read, so `pdfkub-small.svg` draws thicker text lines
and three dots in the bubble instead.

**Provenance:** generated by [`packaging/make_icon.py`](../../packaging/make_icon.py). The word is Kanit Bold
(SIL OFL 1.1, [OFL-Kanit.txt](OFL-Kanit.txt)) converted to outlines, so no font is needed to draw it.

## Files

| File | What it is |
|---|---|
| `pdfkub.svg` | the master vector; every PNG, `.ico` and `.icns` at 32 px and up is rendered from it |
| `pdfkub-small.svg` | the 16–24 px variant (no lettering) |
| `pdfkub-1024.png` | 1024 px on Apple's grid; also the runtime Dock icon on macOS |
| `pdfkub.icns` | macOS icon (16–1024 px) |
| `pdfkub.ico` | Windows icon (16–256 px), embedded in `pdfkub.exe` by `apps/pdfkub/build.rs` |
| `hicolor/<n>x<n>/apps/io.github.teh_natsu.pdfkub.png` | Linux hicolor theme, 16–512 px; the 256 px one is the runtime icon on Windows and Linux |
| `hicolor/scalable/apps/io.github.teh_natsu.pdfkub.svg` | Linux scalable icon (copy of the master) |

Where it shows: `apps/pdfkub/src/main.rs` sets the window icon (Dock, taskbar, Alt-Tab, launcher) and the
Wayland app id `io.github.teh_natsu.pdfkub`; `packaging/linux/io.github.teh_natsu.pdfkub.desktop` names the
hicolor icon; the About dialog and home screen show `pdfkub.svg`.

## Regenerate

```sh
python3 packaging/make_icon.py Kanit-Bold.ttf assets/app-icon   # needs fontTools; Kanit-Bold.ttf from google/fonts
packaging/icons.sh        # needs resvg and python3 (Pillow for the .icns off macOS)
cargo xtask assets        # then update the sha256 values in ATTRIBUTION.toml and run with --write
```
